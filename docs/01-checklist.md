# WEDDING CHECK LIST

> 출처: 웨딩 박람회에서 배포한 인쇄물 1장 (사진)
> **인쇄된 표만 옮겼다.** 상담 중 손으로 적은 메모는 개인 기록이라 제외했다.
> 🔎 = 사진 판독이 불확실한 부분

원본 표 구성: `구분` / `품목` / `내용` / `예상비용` / `비고`
금액 단위는 별도 표기가 없으면 **만원**.

## 이 문서에 없는 것

원본 인쇄물에는 상담 중 손으로 적은 메모(동그라미 · X 표시 · 금액)가 함께 있었다.
**그건 특정 커플의 결정이므로 이 문서에 옮기지 않았다.** 여기 있는 것은
박람회가 모든 방문자에게 배포한 인쇄면뿐이다.

앱에서 각자의 선택과 금액을 다루는 방식은 [design/](../design)의 시안을 참고.
