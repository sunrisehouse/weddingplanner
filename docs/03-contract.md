# 웨딩상품 계약서 — 양식 구조

> 출처: 웨딩 박람회에서 작성한 스드메 계약서 1장 (사진)
> **계약서 양식과 인쇄된 안내 문구만 옮겼다.**
> 채워진 값(금액 · 날짜 · 성명 · 연락처 · 업체명 · 계좌번호)은 개인 기록이라 전부 제외했다.
> 🔎 = 사진 판독이 불확실한 부분

이 문서의 목적은 **스드메 계약이 어떤 항목으로 이루어지는가**를 남기는 것이다.
얼마를 냈는지가 아니라, 무엇을 확인해야 하는지가 중요하다.

## 3. ⭐ 필수 / 별도 / 위약금 안내

계약서 우측에 **인쇄·강조되어 있는** 문구. 계약 금액에 포함되지 않는다.

### 스튜디오
- **원본 ○○만원~** / 수정본 포함 (업체별 상이)
- 선수정본 별도
- **촬영기준 90일 이내 변경/취소 시 위약금 발생**

### 드레스
- **헬퍼비 : 촬영 & 본식 각각 발생**
- 촬영 : 특정 구 외 지역 출장비 발생 (5시간 기준)
- 본식 : 서울 외 출장비 발생
- **투어비 : 샵당 발생**
- 예약 및 일정 변경, 옵션 변경·취소 시 위약금 별도 발생
- 블랙라벨 등 별도 발생 🔎

### 메이크업
- **얼리스타트(8시 이전) 별도**
- 테이블 비용 별도 (17시 이후)
- 컷 / 펌 / 헤어피스 / 본식 변경 옵션 별도
- 헤어 변경 옵션 별도

### 공통
- 구성·일정 변경, 옵션 선정 시 비용 발생 (업체별 상이)

> 금액은 업체·시기마다 다르므로 이 문서에 옮기지 않았다.
> **중요한 건 금액이 아니라 "이 항목들이 계약 금액 밖에 있다"는 사실이다.**

## 4. 결제 구조

계약서에 **인쇄된** 비율.

| 구분 | 비율 |
|------|------|
| 계약금 | 10% |
| 촬영 60일 전 | 70% |
| 본식 60일 전 | 20% |

- VAT 포함 여부를 계약서에서 확인
- 결제 방식: ☐ 계좌이체 / ☐ 현장결제

> 결제 기한이 **촬영일 60일 전 / 본식일 60일 전**이라는 점이 중요하다.
> 촬영일이 바뀌면 중도금 납부일도 함께 움직인다.

## 5. 위약금이 걸리는 지점

| 규칙 | 내용 |
|------|------|
| 변경·취소 위약금 | **촬영일 기준 90일 이내** 변경/취소 시 발생 |
| 기준 | 업체 약관에 따름 |

```
        위약금 없음          │        위약금 발생 구간
────────────────────────────┼──────────────────────────────▶
                       촬영일 D-90                      촬영일
```

## 이 계약서에서 확인해야 할 것

계약할 때 놓치기 쉬운 순서로 정리한다.

1. **촬영일이 예식일과 별개의 기준일**이다 — 위약금·중도금이 여기 걸린다
2. **별도 항목이 몇 개인지** 세어본다 (원본 · 헬퍼비 촬영/본식 · 투어비 ·
   출장비 촬영/본식 · 얼리스타트 · 레이트 = 8개 이상)
3. 별도 항목 중 **금액이 안 적힌 것**이 있는지 본다 (출장비가 대표적)
4. 결제 기한 두 개(촬영 D-60, 본식 D-60)를 달력에 옮긴다
5. 위약금 경계일(촬영 D-90)을 달력에 옮긴다

> 계약 총액만 보면 실제 지출을 알 수 없다. **별도 항목을 다 세어봐야 한다.**
